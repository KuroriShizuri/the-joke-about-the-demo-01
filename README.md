# The joke about the demo

One line, one demo, one very polite AI coding agent:

> During the demo, my AI agent found the bug, fixed it, then apologized to the audience for my code.

The setup is the most relatable demo moment there is — a bug appearing live in front of an audience. The punchline flips the roles: the agent does the whole job (finds it, fixes it) and then, in the most human gesture possible, apologizes *for my code* — as if the developer were the embarrassment and the agent were the professional on stage. The joke lands because every developer who has demoed beside an agent recognizes that exact feeling: the tool is so competent it starts doing the social work too.

## Run

```sh
python3 main.py
```

Writes the joke (one line plus a trailing newline) to `/output/entry.txt`, or to `$ENTRY_OUTPUT` when set. Python 3.13, standard library only, no network, deterministic.
